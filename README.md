# UnscrambleGame

Игра "собери слово": на экране слово с перепутанными буквами, нужно ввести исходное.

Проект сделан в рамках обучения TDD-разработке: каждая фича начиналась с UI-теста, потом шла реализация.

## Что показывает проект

- TDD: сценарные UI-тесты (Espresso) пишутся до кода, у каждого сценария есть номер тест-кейса
- Page Object для UI-тестов
- Проверка пересоздания Activity на каждом шаге сценария: каждое состояние проверяется до и после recreate
- Свои Espresso-матчеры для TextInputLayout (hint, текст ошибки) и цвета кнопки
- Unit-тесты для GameViewModel и для UiState каждого кастомного view
- Кастомные view с сохранением состояния через SavedState
- Сохранение прогресса между запусками (SharedPreferences), отдельная разметка для landscape

## Стек

Kotlin, XML/View, ViewBinding, JUnit, Espresso

## Как запустить тесты

Unit-тесты:

    ./gradlew test

UI-тесты (нужен запущенный эмулятор или подключенное устройство):

    ./gradlew connectedAndroidTest
